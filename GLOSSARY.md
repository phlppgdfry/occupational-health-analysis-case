# Begrippen in deze case

| Begrip | Betekenis in de module |
|---|---|
| Aanvraag | Administratieve vraag om een afspraak voor één fictieve medewerker |
| Werkpost | Administratief label; geen diagnose of medisch advies |
| Actieve reservering | Huidige koppeling van een dossier aan een tijdslot |
| Halfopen interval | Start hoort erbij, eindtijd niet; aansluitende afspraken overlappen niet |
| Requirement | Vastgelegd gewenst gedrag met ID, prioriteit, eigenaar en acceptatie |
| Acceptatiecriterium | Controleerbare voorwaarde voor correct gedrag |
| Traceerbaarheid | Verwijzing van behoefte naar requirement, regel, test en meetplan |
| State machine | Toegestane dossierstatussen en overgangen |
| BPMN | Notatie om activiteiten, rollen, keuzes en procespaden weer te geven |
| ADR | Beslisnotitie met context, opties, keuze en gevolgen |
| Optimistische versiecontrole | Opdracht wordt geweigerd wanneer de gelezen versie verouderd is |
| Idempotentie | Een identieke herhaalde opdracht veroorzaakt geen tweede effect |
| Outbox | Opgeslagen intentie om na een commit een bericht af te leveren |
| UAT | Eindgebruikers toetsen of de oplossing hun taken ondersteunt |
| RACI | Verdeling van uitvoering, eindverantwoordelijkheid, consultatie en informatie |
| RAID | Register van risico's, aannames, issues en afhankelijkheden |
| Go/no-go | Expliciete beslissing of de voorwaarden voor een pilot/uitrol zijn vervuld |
